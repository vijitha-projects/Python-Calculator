# Python Calculator
A simple calculator built using Python.
## Features
- Addition
- Subtraction
- Multiplication
- Division
- Prevents division by zero
## Technologies Used
- Python 3.13
## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run:
```bash
python calculator.py
```
